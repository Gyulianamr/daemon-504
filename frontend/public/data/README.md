# public/data/

Datos fijos del juego (Genesis, tarea A2-01). Las probabilidades de exploración y aparición viven aquí, no en las pantallas.

- `criaturas.json` — 20 criaturas: 3 iniciales, 13 salvajes y 4 guardianes.
- `zonas.json` — 8 lugares: conexiones, sello requerido, pesos de eventos, tabla de apariciones, tienda y guardián.
- `objetos.json` — TamaBall, MegaBall y Curaball.
- `tipos.json` — ventajas entre tipos (×1.5).
- `eventos.json` — textos de eventos especiales.
- `partida-demo.json` — cuenta de prueba.
