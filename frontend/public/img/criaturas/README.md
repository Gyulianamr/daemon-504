# public/img/criaturas/

Una imagen por especie. El nombre del archivo es el `id` de la criatura en el catálogo: `1.svg` (Flamix), `2.svg` (Aquabit)… `20.svg` (Umbráculo).

- Las imágenes son propias del equipo (emblemas por tipo). Se pueden reemplazar por dibujos propios conservando el nombre del archivo.
- No se usan imágenes de franquicias existentes.
- Tamaño recomendado: cuadradas, 96 × 96 px o más.
- Si falta una imagen, `ImagenCriatura.jsx` no muestra nada y la tarjeta queda solo con texto.
