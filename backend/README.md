# backend/

Se construye en el **Avance 3** (Node.js + Express + Supabase PostgreSQL).

Cada función de `frontend/src/js/servicios/` tiene escrito el endpoint que la reemplazará
(por ejemplo `// Futuro: POST /api/exploracion`). En el Avance 4 el interior de esas funciones
pasa a usar `fetch()` contra esta API y las pantallas no cambian.
